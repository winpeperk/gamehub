# GameHub
Проект представляет собой REST API для каталога видеоигр. Система позволяет выполнять CRUD-операции над играми, а также осуществлять поиск и фильтрацию по различным параметрам. API проектируется в соответствии с REST-принципами.
## Sprint Review
В рамках спринта были закрыты задачи по созданию модели Game и реализации CRUD API для игр.
По итогу спринта был доставлен базовый REST API для каталога игр с возможностью управления сущностями.
Задачи по поиску, фильтрации и документированию API не были завершены и перенесены в следующий спринт.
## Sprint Retrospective
